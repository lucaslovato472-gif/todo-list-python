# Gerenciador de Tarefas em Python

Projeto feito em Python para gerenciamento simples de tarefas no terminal, com salvamento de dados em formato JSON.

## Funcionalidades
-**Visualizar tarefas:** Exibe a lista de tarefas com o status de concluída `[✓]` ou pendente `[ ]`.
-**Adicionar tarefa:** Registra novas atividades na lista.
-**Marcar como feita:** Atualiza o status de uam tarefa para concluída.
-**Excluir tarefa:** Remove um item da lista.
-*Persistência de dados:** Todas as alterações são salvas automaticamente em um arquivo `.json`.

## Tecnologias utilizadas
-**Python 3**
-**Módulos nativos:** `json`e `os`
